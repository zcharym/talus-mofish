Echo Watch

Pair this PWA to receive build alerts from your local desktop watcher.

Add to Home Screen

iOS only supports push when Echo Watch is installed as a Home Screen app.

  1. Tap Share in Safari.
  2. Choose Add to Home Screen.
  3. Open Echo Watch from your Home Screen, then tap Enable Notifications.

How it works

  • echo-watch runs on your local PC, never inside the VDI.
  • It watches the VDI client window and sends minimal alerts to Cloudflare.
  • This PWA receives Web Push via Apple's web.push.apple.com on iPhone.
